04 / AI 词典

把热词变成可操作的概念

Agent / 智能体
能规划步骤、调用工具并根据结果继续行动的模型系统。
RAG / 检索增强
先从外部知识库检索，再把相关上下文交给模型生成答案。
MCP
让模型以统一协议发现并使用外部工具、资源与提示。
量化 Quantization
降低权重精度以减少显存和存储开销，常见于本地推理。
推理 Inference
模型使用既有参数对输入执行预测或生成的过程。
LoRA
用少量可训练低秩矩阵适配基础模型的参数高效微调方法。
GGUF
面向 llama.cpp 生态的可扩展模型存储格式，支持量化权重。
Embedding
把文本、图像或代码转换为可用于相似度计算的向量。
Trending Score
Hugging Face 模型接口提供的趋势指标；本站直接展示它，不冒充下载增长。
